# مولّد جدول الدورات

صفحة ويب تقرأ الدورات من Google Sheet وترسم الجدول بتصميم خيركم، ثم تحمّله PNG.

## الإعداد (مرة واحدة)
1. ارفع `courses.csv` إلى Google Sheets (File > Import) أو انسخ محتواه.
2. من الشيت: File > Share > Publish to web > اختر الشيت و **CSV** > Publish، وانسخ الرابط.
3. ضع الرابط في `config.js` داخل `SHEET_CSV_URL`.
4. فعّل GitHub Pages: Settings > Pages > Branch: `main` / root.

## الاستخدام
افتح رابط الصفحة، اكتب سطر التاريخ، اضغط "تحديث من الشيت" ثم "تحميل الصورة".
الترقيم يتولد تلقائياً، والصورة تطول مع عدد الصفوف.

يمكن أيضاً تمرير الرابط مؤقتاً: `index.html?csv=<رابط>`، أو رفع ملف CSV يدوياً.

## أعمدة الشيت (الصف الأول عناوين)
اليوم، التاريخ، اسم الدورة، عدد الأيام، عدد الساعات، التوقيت، المدرب.
سطرا الهجري والميلادي في خلية التاريخ يُفصلان بسطر جديد (Alt+Enter).
